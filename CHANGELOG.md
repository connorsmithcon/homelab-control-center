# Changelog

All notable changes are documented in this file.

## 0.1.0 - 2026-09-12

### Added

- Local-first responsive control-center dashboard
- Local and agentless SSH Linux monitoring
- Host resource, service, journal, and update views
- Local scrypt authentication, opaque sessions, and CSRF defense
- SSH host-key probe and explicit trust workflow
- Narrow root action broker over a group-restricted Unix socket
- Versioned checksum-verifying installer
- Update, rollback, doctor, bootstrap-token, node-key, and uninstall commands
- Architecture, authentication, permission, security, and operations documentation
